# 애플 건강 가져오기 — 시험 지원

실제 Apple 기기의 내보내기 파일은 아직 검증하지 않았다. 이 기능은 공개된 내보내기 구조를 참고해 만든 **합성 XML/ZIP**으로 검증했다. 지원 안내를 가져오기 전과 가져온 화면에 표시한다. 모든 Apple Watch/iOS 버전과 타사 운동 앱 호환을 보장하지 않는다.

## 현재 범위

- 건강 앱 → 요약 → 프로필 → 모든 건강 데이터 내보내기. 원본 ZIP 또는 그 안의 `export.xml`을 선택한다. 포맷은 내용으로 구분한다.
- XML의 직접 자식 `Workout` 중 `HKWorkoutActivityTypeRunning`만 읽는다. 날짜, 명시 시간대, 운동시간, 거리, `WorkoutStatistics`에 있는 평균·최대 심박을 사용한다.
- 예전 `totalDistance`와 `totalDistanceUnit`, 최근 `WorkoutStatistics`의 거리 `sum`을 지원한다. 두 값이 충돌하면 거리를 표시하지 않는다. 명시 단위만 변환한다. 빈 값·알 수 없는 단위는 null이며 0이나 추정값으로 채우지 않는다.
- 운동시간은 `duration`을 사용한다. 시작–종료 시각 차이로 대신 계산하지 않으므로 일시정지를 운동시간으로 더하지 않는다.
- 기록 목록, 요약, 최근 4주 활동, 합계·월별 거리, 두 러닝 전체 요약 비교, 선택형 기기 보관·복원을 지원한다.
- **시간별 그래프, 전후반 복기, 같은 구간의 심박·페이스 비교는 미지원**이다. 요약 평균으로 가짜 시계열을 만들지 않는다. `Record`의 심박·속도나 GPS로부터 값을 복원하지 않는다. 기존 삼성헬스 시간별 분석은 유지한다.
- 동일 출처·시작/종료·정규화 요약값이 같은 복사본만 합친다. 출처가 불명확하거나 값이 다르면 임의로 병합하지 않는다. 시간대가 겹치는 운동은 중복 가능성을 표시하고 기본 시간·거리 합계에서 제외한다. 원본·분석 설정에서 확인 후 포함할 수 있다.

## 처리와 개인정보

Worker에서 XML을 SAX 방식으로 조금씩 읽는다. ZIP은 512 MiB, XML은 압축 해제 후 1 GiB, 러닝 5만 개, 중첩 32단계, 미완성 토큰 약 1 MiB 한도다. 정상 형식의 대형 파일도 저사양 기기에서 느리거나 메모리가 부족할 수 있다. 취소는 Worker를 종료한다.

건강 XML 전체를 스캔하지만 러닝 요약 이외의 건강 레코드는 결과에 남기지 않는다. 이름을 포함할 수 있는 `sourceName`과 `device`는 파서 내부 중복 확인에만 쓰고 반환 전에 버린다. UI/보관 데이터에는 익명 `출처 1/2/…`만 남는다. 실제 기기 모델로 해석하지 않는다. GPS 경로, CDA 문서, ECG 파일은 압축 해제하지 않는다. 원본 XML·ZIP, 프로필, 이름, 기기 식별자, GPS는 저장·전송하지 않는다.

내부 DTD 선언은 허용하되 사용자 정의 ENTITY와 외부 DTD는 거절한다. 외부 리소스를 조회하지 않는다. 잘못 닫힌 XML·잘못된 루트·중복 속성은 실패 처리한다. 다른 원본이 섞인 ZIP, 중복 경로, 경로 이탈, 암호화 파일도 거절한다. 실패한 가져오기는 이전에 보관한 정상 데이터를 덮어쓰지 않는다.

## 검증과 후속 확인

합성 테스트는 두 거리 형식, 단위, 날짜·시간대, 일시정지 요약, 결측·충돌, 중복·겹침, XML 손상·엔티티·크기/중첩 제한, ZIP/단독 XML, 취소를 다룬다. 모바일 Chromium/WebKit에서 읽기→전체 요약 비교→기기 보관→새로고침, 개인정보가 보관 데이터에 남지 않음, 외부 요청 없음, 320px 레이아웃을 확인한다.

실제 파일 확보 후 확인할 항목: iOS/건강 내보내기 버전, 운동 앱별 요약 필드와 단위, 운동 통계의 범위, 일시정지 이벤트, Workout과 Record의 출처/시간 연결, 속도 샘플의 축약, 대형 파일 및 실기기 메모리. 이 검증 전에는 시간별 분석을 지원한다고 표시하지 않는다. 파일 제공 없이 기본 지원 개발은 가능하며, 향후 실제 호환 검증은 기기 소유자가 로컬에서 할 수 있다.
