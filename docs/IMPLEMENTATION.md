# 구현 상태 v0.1.0

2026-10-08. 디자인 시안에서 실제 React/Vite 정적 앱으로 전환했다. 공개용 가짜 데이터나 실제 개인 기록을 제품 번들에 넣지 않았다.

## 데이터 흐름

`File → 앱 전용 Worker → BlobReader/ZIP 중앙 목록 → 주 exercise CSV → 러닝 1002 → 연결된 JSON 순차 읽기 → 요약·관측 프로필 → UI`

ZIP 전체를 arrayBuffer로 가져오지 않는다. Worker에서 원본 File과 참조를 보관한다. 내부 zip.js Worker는 비활성화하며, 취소·초기화는 앱 Worker를 terminate한다. 상세 캐시는 최대 3회·추정 32 MiB, 프로필 입력은 약 50만 표본으로 제한한다. 상세 읽기는 직렬화하고 대기 중인 요청은 가장 최신 것만 유지한다. 메인 스레드는 requestId로 오래된 응답을 무시한다.

프로필은 1초 단위 페이스 bin의 실제 심박 값·관측시간·비교 가능시간을 담는다. 모든 러닝의 전체 시계열을 React에 복사하지 않는다. 선택한 러닝의 원본 정규화 포인트만 상세 화면에 반환한다. 50만 표본 제한은 다음 기록을 읽기 전 적용하므로 한 기록의 최대 10만 포인트만큼 초과할 수 있다. 메모리 추정치는 OS 보장 상한이 아니다.

### 파서

- 정확한 basename으로 주 CSV를 찾는다. 여러 주 CSV가 들어 있으면 임의 병합하지 않고 안내한다.
- 메타데이터/BOM/CRLF, 따옴표, 명시적 필드 별칭, 추가 마지막 빈 열을 처리한다. 유의미한 추가 열과 날짜 오류 행은 제외 개수를 표시한다.
- CSV UTC 문자열·명시 시간대 문자열을 epoch로 처리한다. time_offset은 현지 날짜에만 적용한다. 확인되지 않은 수치 offset은 단위를 추측하지 않는다.
- UUID는 내부 중복 처리용. UI ID는 순번이며 리포트에도 원본 식별자를 넣지 않는다.
- 음수·NaN·Infinity·빈 값은 제외한다. HR=0은 결측, speed=0은 정지 상태로 보존한다. 높은 양수 HR만으로 삭제하거나 위험 판정하지 않는다.
- JSON은 배열·최대 10만 포인트·중첩 깊이 16을 허용한다. 선택한 scalar만 정규화한다.
- 동일 epoch의 보완 지표는 병합하고 충돌 필드는 null로 유지한다. 충돌 이후의 복사본으로 값을 되살리지 않는다.
- JSON interval/cumulative 후보를 CSV 총거리와 검증한다. 두 후보 모두 맞거나 둘 다 불일치하면 unknown. 구간 거리의 방향은 미확정이므로 구간거리 추정은 제공하지 않는다.
- 간격 중앙값의 3배, 최대 60초를 넘는 공백을 연결하지 않는다. 마지막 표본을 종료 시각까지 연장하지 않는다.

### ZIP 제한

압축 ZIP 512 MiB, 엔트리 10만, CSV 16 MiB, JSON 8 MiB, 작업 중 선택적 압축 해제 출력 128 MiB. 선언 크기와 실제 writable 출력 바이트를 모두 검사한다. CSV는 5만 행 제한. 경로 traversal/절대 경로/중복 경로/모호한 참조/암호화/CRC 손상은 처리하지 않는다. 외부 URL을 참조로 fetch하지 않는다. 무관한 파일의 선언 압축 해제 크기 합으로 정상 내보내기를 거절하지 않는다.

## 화면·그래프

세 탭은 요약·러닝·성장. 날짜·거리 검색과 기간 필터가 공통 적용된다. 화면과 차트 모듈은 필요할 때 로드한다. 초기 그래프 애니메이션은 끈다.

상세의 보기·Y축·선택 관측·고정·확대 범위를 하나의 상태로 관리한다. 겹쳐 보기에서 Y축 눈금만 바꾸며 선 위치는 바뀌지 않는다. 숨긴 보조 Y축 폭은 0으로 지정해 눈금이 차트 왼쪽 밖으로 밀리는 것을 막았다. 자동화에서 눈금의 실제 화면 경계도 검사한다. 페이스는 빠를수록 위, 확대에도 Y축은 전체 러닝 기준이다. 커서는 실제 원본 시각으로 이진 탐색하고 requestAnimationFrame으로 갱신한다. 선/축 컴포넌트를 memo로 분리해 커서 이동 때 데이터 경로를 재계산하지 않는다.

차트 표시 데이터는 메인 스레드의 memo에서 준비한다. 원본 포인트와 계산 경로는 분리했다. 최대 약 1,000개 표시 포인트로 줄이면서 지표별 bucket 최대·최소와 공백/결측 경계를 보존한다. 결측 경계는 원본 값이며, 관측 사이에 삽입하는 공백 표지는 모든 측정값이 null이다. 통계는 원본으로 계산한다. 초기 Worker 집계와 별개로 상세 확대의 표시 준비를 Worker에 옮기는 것은 후속 성능 측정에 따라 검토한다.

터치·포인터·시점 slider, 두 구간 slider, 전체 복귀를 제공한다. 핀치는 아직 없다. 이동 흐름은 0.3/1.8 m/s 경계의 순간 분류가 30초 이상 유지된 구간만 표시한다. 정지 버튼 사용이나 원본 운동 종류로 해석하지 않는다. 리포트는 현재 JSON만 제공한다.

## 홈 화면 설치

매니페스트와 일반/maskable/iOS 아이콘, 26개 iOS 시작 이미지, 밝은/어두운 HTML 로딩 화면을 연결했다. SVG 원본에서 최대 2048px 아이콘과 2160×3840 실행 화면 원본을 생성한다. Service Worker·오프라인 캐시는 추가하지 않았으며 다시 열 때 ZIP을 선택해야 한다. 기기별 설치/시작 화면은 HTTPS 배포 후 실기기 검증이 필요하다. [상세 범위와 생성 방법](PWA.md).

## 계산

- 거리와 운동시간 각각 유효 요약값 합. 전부 결측이면 null. 평균 페이스는 양수 시간·거리가 동시에 존재하는 동일 집합의 합 비율. 기록별 페이스 중앙값은 동일 가중.
- 전체 HR은 양 끝에 실제 심박이 있는 인접 구간의 시간 가중. 한 구간에서 시작점 관측값을 대표로 쓰는 계산 가정이며 결측·공백·마지막 꼬리는 제외. CSV 평균 HR은 상세 상단에 따로 표시.
- 성장: 시작 5분·속도 1.8 m/s 미만·결측·긴 공백·다음 속도 20% 초과 전환 제외. 지정 페이스 ±15초에서 20표본·180초·커버리지 70% 이상일 때 기록 중앙 HR 계산. 주는 현지 월요일, 월은 달력 기준. 기간별 대표값은 적격 러닝 중앙값들의 중앙값. 적격 3회 미만 참고용.
- 산점도는 위 동시 관측의 최대 900점, 페이스 위치는 1초 bin 중앙. 이는 화면 해상도 축소이며 표본 수는 원본이다.
- 드리프트: 시작 5분 이후 적격 관측이 연속 20분 이상이고 두 절반 속도 차이 ≤5%, 커버리지 ≥80%. 절반 경계에서 시간 가중치를 정확히 나눈다. 효율 = 평균 속도/평균 HR, 변화 = 100×(전반−후반)/전반. 조건에 맞는 가장 긴 후보 구간 하나.
- 관찰: 30초 이하·20 bpm 변화; HR/케이던스 동시 30표본·180초·상관 ≥0.8·차이 중앙값 ≤10·양쪽 분산 존재; 감속 20% 후 60초 창 HR 비교; 사용자가 정한 HR 이상 60초. 감속 후보는 실제 관측에서 최소 10초 간격으로 검사하며 고밀도 6,000표본 초과 창은 보류.
- 개인 비교는 현재 제외, 이전 적격 최대 10회 중 최소 5회, 중앙절대편차(MAD)>0. 3×1.4826×MAD 초과 차이만 관찰. 건강 점수나 진단을 만들지 않는다.

## 개인정보

원본 ZIP·건강값은 메모리에만 있다. localStorage는 테마와 그래프 보기 설정뿐이다. GPS·사진·프로필·메모를 모델에 포함하지 않는다. 외부 폰트/CDN/분석/오류 수집이 없다. 초기화와 종료는 Worker/상태/파일 input/캐시/리포트 object URL 참조를 해제한다. 물리적 메모리의 즉시 삭제를 보장하지 않는다.

배포 CSP는 `connect-src 'none'`, 로컬 script/Worker만 허용한다. 정적 앱 전달에는 호스팅의 일반 요청 기록이 발생하며, 선택한 ZIP과 분석값은 보내지 않는다. 리포트에는 날짜·건강 수치가 있으므로 완전히 비민감한 자료라고 부르지 않는다.

## 검증과 남은 확인

- TypeScript + Vite production build 성공.
- Vitest 28개 통과: 파서·지표·부족 데이터·표시 점 제한/피크/결측·ZIP 선택 읽기/안전 제한.
- Playwright 10개 통과: 모바일 Chromium/WebKit, 320px, 파일 선택 지정, 손상 ZIP 복구, 취소/재선택, 실제 시점 동기 커서, 보기/축/구간 보존, 성장, 기간 필터, 리포트 식별자 제외, 테마, 초기화, 매니페스트/아이콘/시작 이미지의 연결·해상도, JS 전 로딩 화면, Service Worker·Cache Storage 미사용.
- 같은 배포 CSP 하에 테스트하며 외부 요청과 POST/PUT 등 데이터 전송 없음 확인.
- 제공된 실제 ZIP에서 러닝 전부 선택 읽기와 상세 파서·집계 검증 통과. 개인 결과는 `.local/`에만 있음. 이 하나의 ZIP으로 모든 삼성헬스 버전 지원을 주장하지 않음.
- Samsung Internet·실제 Android Chrome/iPhone Safari의 OS 파일 선택창·터치 스크롤·메모리 압박은 아직 실기기 검증 전. 자동화 WebKit을 Safari 실기기와 동일시하지 않음.
- 같은 기기만 비교하는 필터, 기기별 익명 그룹, 핀치, HTML/PDF 리포트는 아직 미제공.
- 500ms 첫 렌더/100ms 조작 목표는 실제 휴대폰 측정 전. 저사양 기기에 512 MiB 처리가 가능하다는 보장이 아님.
- Vercel 설정 준비 완료, CLI 로그아웃으로 실제 배포 미완료. 인증 후 호스팅 헤더·ZIP/Worker·외부 요청을 확인해야 함.
