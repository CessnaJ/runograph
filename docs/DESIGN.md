# runograph 화면 및 디자인 v0.2

상태: **미니멀 기록장 방향 확정** (2026-10-08 사용자 선택). 그래프의 초기 렌더링과 이후 인터랙션을 우선 설계한다. 세부 화면과 그래프 동작은 구현 전 검토 중이다.

## 정보 구조

사용자는 세 목적을 모두 큰 탭으로 보는 방향을 제안했다. 모바일 탐색은 `요약 · 러닝 · 성장`으로 제안하고 시인성을 우선한다. 설정은 상단 메뉴. 러닝 상세는 러닝 탭의 기록 목록에서 들어가는 하위 화면. 데스크톱은 동일 메뉴를 상단 또는 왼쪽에 배치한다.

| 화면 | 핵심 내용 | 주요 행동 |
| --- | --- | --- |
| 시작 | 로컬 분석 설명, ZIP 선택, 개인정보 안내, 내보내기 도움말 | ZIP 선택 |
| 처리 중 | 현재 단계, 해당 단계 진행 수·용량, 취소, 대용량 안내 | 취소 또는 기다리기 |
| 분석 완료 안내 | 읽은 러닝 수, 상세 연결 상태, 제외/문제 요약 | 요약 보기 / 처리 상세 |
| 요약 | 기간 필터, 총 거리·횟수·시간, 평균/중앙 페이스, 심박 출처, 월별 변화, 관찰 카드 | 기록 또는 성장으로 이동 |
| 기록 | 날짜 범위, 날짜 검색, 최신순/과거순, 거리·시간·페이스·심박·데이터 상태 | 러닝 상세 열기 |
| 러닝 상세 | 요약, 심박·페이스·케이던스, 상태 띠, 선택 구간 통계, 관찰 근거 | 시간 확인 / 구간 선택 / 확대 해제 |
| 성장 | 페이스 구간 선택, 심박 산점도, 날짜/주/월 추세, 표본 정보, 드리프트·효율 | 비교 조건 변경 / 기록 열기 |
| 설정 | 시스템/밝게/어둡게, 데이터 처리 설명, 리포트 저장, 초기화 | 설정 변경 / 다운로드 / 초기화 |

## 모바일 배치 원칙

- 첫 화면의 한 가지 주요 행동은 ZIP 선택. 별도 로그인이나 사용자 정보 입력 없이 시작.
- 요약 상단에서 기간을 항상 확인할 수 있음. 주요 지표는 2열, 그래프는 한 열. 긴 설명은 `계산 기준`에서 펼침.
- 검색은 원본 건강 메모를 읽지 않고 날짜와 화면의 자동 러닝 라벨을 대상으로 한다. 세션 UUID를 검색값으로 노출하지 않는다.
- 상세는 `나눠 보기 / 겹쳐 보기`를 전환할 수 있다. 기본은 같은 시간축의 세로 3개 그래프. 겹쳐 보기는 한 영역에 세 선을 표시하고 지표별 축 범위와 단위를 구분한다. 보기 전환에도 선택 시점과 확대 구간을 유지한다.
- 차트 한 번 탭: 커서 고정 및 같은 시각의 세 지표 표를 차트 밖에 표시. 결측 지표는 `—`, 근처 값을 보여줄 때는 실제 측정시각을 함께 표시.
- `구간 선택`을 눌러 시작/끝 핸들을 조작하고 확대. 드래그가 어려우면 시작/끝 시간 입력으로 동일 동작 제공. 페이지 스크롤과 구간 조작을 구별.
- 핀치 확대는 탐색 과제로 둔다. 출시 필수 조건은 터치 핸들·시간 입력으로 확대/구간통계를 이용할 수 있는 것.
- 정지/걷기/달리기는 원본 확정 상태가 없으면 `추정` 표시. 결측은 별도 상태. 속도만으로 달리기를 확정하지 않는다.
- 차트 빠른 페이스는 위쪽, 느린 페이스는 아래쪽으로 표시하고 축 단위를 명시. 선은 결측/긴 공백을 가로질러 이어지지 않음.
- 로딩 시 가짜 정밀한 전체 백분율을 만들지 않는다. `ZIP 목록 읽기 → 운동 CSV → 러닝 상세 N/M → 분석` 단계와 측정 가능한 진행률을 표시.

## 확정한 디자인 방향

### 미니멀 기록장 — 사용자 선택

뉴트럴 배경과 가는 구분선, 날짜·기록 목록 중심. 시작 화면도 짧은 안내와 단정한 작업 행으로 구성한다. 장식적인 카드 수를 줄이고 그래프와 비교표가 우선한다. 사용자는 이 방향을 가장 트렌디하다고 평가했고, 시인성은 그래프의 첫 표시와 조작 경험에서 확보하도록 요청했다.

## 제안 디자인 규칙

시스템 한글 글꼴, 탭형 숫자, 본문 16px 이상, 보조 13px 이상, 터치 대상 44px 이상. 간격 4/8/12/16/24/32px. 그래프는 프레임을 최소화하고 화면/입력 컨트롤의 기본 모서리는 12px로 제안한다. 실제 앱에서는 명암 대비를 검증한다.

차분한 녹색을 행동과 선택에 사용한다. 심박·페이스·케이던스는 일관된 선 색과 지표명·단위로 구분하고 어두운 모드에서 가독성을 별도로 확인한다. 심박 선 색을 위험 등급으로 해석하도록 만들지 않는다. 색만으로 상태를 전달하지 않는다. reduced-motion과 키보드 탐색, 그래프의 표 형태 대체 설명을 제공한다.

## 그래프 경험 설계

[그래프 세부 스펙](GRAPHS.md)에 초기 렌더링, 축 정책, 관측값 표시, 동기 커서, 구간 확대, 접근성과 성능 검증을 정리한다. 구현용 라이브러리보다 먼저 사용자가 보게 될 상태와 동작을 확정한다.

## 빈 상태와 오류 문구

| 상황 | 제안 문구/행동 |
| --- | --- |
| 선택 전 | `러닝 기록을 기기 안에서 살펴보세요` / `삼성헬스 ZIP 선택` |
| 대용량 | `파일이 커서 시간이 걸릴 수 있어요. 필요한 운동 파일만 읽습니다.` |
| 러닝 없음 | `이 파일에서 러닝 기록을 찾지 못했어요` / 지원 형식·다른 ZIP 안내 |
| 상세 없음 | `운동 요약은 있지만 시간별 측정 데이터가 없어요` / 요약 이용 가능 |
| 심박 없음 | `이 기록에는 심박 측정값이 없어요` / 페이스 등 가능한 지표 표시 |
| 성장 조건 부족 | `현재 조건으로 비교할 기록이 부족해요` / 횟수·시간·제외 이유 및 기간/페이스 조정 |
| 관찰 없음 | `분석 가능한 구간에서 설정 조건에 맞는 관찰이 없어요` |
| 처리 일부 실패 | `일부 상세 파일을 읽지 못했어요` / 가능한 결과 및 실패 수 표시 |
| 손상/암호화/제한 | 원인을 구분하고 재내보내기·다른 파일 선택 안내 |
| 취소/메모리 실패 | 부분 분석을 완성된 결과로 표시하지 않고 재시도/요약만 보기 제공 |

제품 시안은 숫자와 그래프를 가짜 분석 결과로 채우지 않는다. 그래프 시안에는 실제 러닝 한 기록의 허용된 지표만 사용하고 날짜·UUID·위치는 포함하지 않는다. 시안은 의료적 해석이나 성장 결론을 생성하지 않는다.
