# 분석·복기 고도화 스펙 v0.5

2026-11-10. 기존 로컬 처리·기본 메모리 전용·선택형 기기 보관·세 탭 구조를 유지한다. 개인 내보내기 파일과 진단 수치를 이 문서나 테스트에 복사하지 않는다.

## 사용자 흐름

1. 불러오기 직후 추가 클릭 없이 최신 러닝의 특징, 실제 관측 미니 그래프, 측정 상태를 보여준다.
2. 적격 과거 기록이 있으면 ‘비슷한 날짜 기록과 보기’를 한 번 눌러 두 기록의 비교 결과를 연다. 직접 선택은 계속 제공한다.
   자동 비교에서는 기록 선택을 접어 결과를 먼저 보여주고, 직접 고르기로 진입하면 선택을 펼친다.
3. 분석 탭은 질문 → 답 또는 보류 이유 → 그래프 → 사용 기록·기간 → 접힌 조건 조정 순서다. 조건이 다른 결과의 큰 차이 숫자는 대표 정보로 사용하지 않는다.
4. 기본 비교의 한계를 유지하면서 사전에 정한 다른 기간·운동 시점의 비교를 별도로 제안한다. 제안 한 번으로 해당 조건의 상세 분석을 연다.
5. 모든 근거 버튼은 실제 구간으로 이동하며 복귀 시 조건과 스크롤을 유지한다.

## 최근 러닝 복기

- 주 관측 범위의 실제 시간 가중 요약을 최대 60개 구간으로 만든다. 심박·속도는 각각 관측률을 판정하며 빈 값을 연장하지 않는다.
- 고정된 마지막 180초와 직전 300초를 비교한다. 양쪽 속도 관측률 90% 이상, 페이스 차이 20초/km 이상 및 속도 증가 10% 이상을 요구한다. 마지막 세 1분의 측정률이 모두 90% 이상이며, 마지막 1분을 포함한 두 구간 이상에서 같은 증가 조건을 만족할 때 마지막 가속을 대표 문장으로 쓴다. 가장 큰 차이를 만드는 구간을 검색하지 않는다.
- ‘유지하다 가속’은 앞의 두 구간이 충분히 길고 속도 차이 5% 이내일 때만 쓴다. 그 외에는 마지막 구간의 변화만 기술한다.
- 위 조건을 충족하지 않으면 기존 적격 전후반 복기 또는 측정 가능한 페이스 흐름을 제공한다. 심박이 없으면 심박 변화 문장을 만들지 않는다.
- 측정 비율과 비교용 안정 구간을 별도로 표시한다. 안정 3분에 부족해도 유효한 기록의 직접 복기는 제공한다.

## 유사 기록 제안

- 현재 기록보다 이전인 최근 56일, 다른 현지 날짜, 같은 알려진 익명 기기·출처, 요약 시간 포함·성장 제외 아님을 요구한다.
- 두 기록의 고정 5–20분 구간에서 동시 관측률 90% 이상, 상세 평균 페이스 차이 8% 이내, 전체 운동시간 차이 35% 이내를 요구한다.
- 순위는 상세 페이스 차이/8% + 운동시간 차이/35%, 동률은 최근 날짜와 안정적인 내부 키로 결정한다. 심박 변화·좋은 결과·개선 폭은 사용하지 않는다.
- 최대 세 후보를 제공한다. 조건에 맞는 기록이 없거나 짧은 기록·애플 요약이면 직접 선택을 기본으로 제공한다.
- 코스·목적·강도가 같다고 주장하지 않는다. 매칭 임계치는 제품의 탐색 규칙이며 의학적 경계가 아니다.
- 두 러닝의 차이는 실제로 함께 관측된 같은 경과시간 교집합으로 계산한다. 지표별 관측의 서로 다른 시점을 비교하지 않는다.

## 과거 관측 범위

- 현재를 제외한 적격 과거 기록에서 같은 분 구간의 페이스도 8% 이내로 맞춘다. 각 분에 최소 다섯 날짜가 있어야 한다.
- 한 날짜의 러닝이 기준을 독점하지 않게 날짜별 기여를 제한한다. 기준은 러닝별 평균 심박의 중앙값·P25–P75다.
- 현재 심박과 과거 범위를 같은 축에 표시한다. 없는 분의 범위는 잇지 않는다. 이름은 ‘과거 비슷한 기록 범위 (중앙 50%)’이며 정상 범위·신뢰구간으로 부르지 않는다.

## 비교 조건 탐색과 민감도

- 속도 CV 8%, 안정 문맥 120초, 속도/동시 관측률 80%, 5분 준비 구간 제외 등 기존 분석 기준을 유지한다.
- 기본 기간은 최신 시간대 확인 날짜 기준 28일씩, 운동 5–20분이다. 마지막 적격 기록 날짜로 종료일을 몰래 이동하지 않는다.
- 보조 탐색 후보는 28/56일씩 × 운동 5–20/10–20/10–25분이다. 각 후보의 목표와 기기는 기존 공통 입력 범위·근거량으로 정한다.
- 후보 선택에는 결과 차이의 크기·부호를 사용하지 않는다. 양쪽 실제 입력·운동 시점 일치, 기기, 근거량, 최근성을 우선한다. 원래 질문의 상태를 보조 결과로 덮지 않는다.
- 같은 질문에 적격 후보가 없으면 다른 질문의 적격 후보를 구분해 제안한다. 다른 질문임을 제목에 표시하고 적용 버튼은 질문과 조건을 함께 바꾼다. 다른 질문의 변화량으로 현재 질문의 답을 대신하지 않는다.
- 기간·운동 시점·사용 기록 수를 명시하고 코스·계절 보정이나 체력 향상으로 해석하지 않는다.
- 기본 폭 변형·한 러닝 제외에 더해 안정 문맥 90/120/180초 × CV 5/8/12%를 같은 비교 조건에서 검사한다. 방향 변경과 지원/조건 상태 변경을 구분한다.
- 변형의 최솟값·최댓값은 ‘확인한 설정의 범위’이며 신뢰구간이 아니다. 결론이 불안정할 때 단일 좋은 방향 숫자를 크게 강조하지 않는다.
- 원본 상세에서 안정 창 변형을 한 번 생성해 작은 프로필에 저장한다. 조건 변경에 원본 ZIP을 다시 읽지 않는다. 순수 비교와 후보 탐색은 이 작은 프로필만 사용한다.

## 품질·보관·리포트

- 요약과 상세 평균속도의 차이가 10%를 넘고 상세 속도 관측률 90%·5분 이상이면 출처 차이를 알린다. 어느 값을 자동 대체하거나 합계에서 제외하지 않는다.
- 짧게 측정된 움직임을 미측정으로 바꾸지 않는다. 운동시간·연속 달리기 표본 중앙값은 짝수 개일 때 가운데 두 값의 평균이다.
- 전역 필터로 비교 기준일이 범위 밖에 놓이면 명시하고 현재 선택 기록으로 다시 찾을 수 있게 한다. 직접 조절한 조건의 유지와 자동 초기 조건을 구분한다.
- 새 compact 복기와 안정 창 캐시는 선택형 기기 보관에 포함한다. 계산 버전을 올려 필요한 프로필이 없는 이전 보관 자료를 새 결과처럼 사용하지 않는다.
- 리포트에 계산 버전, 비교 조건, 사용/제외 여부, 민감도 검사 범위를 남긴다. UUID·기기 원문·GPS·원본 파일명은 계속 제외한다.

## 완료 검증

- 합성 자료: 마지막 가속/지속 없음/걷기·정지·결측/심박 없음, 결과값과 독립적인 후보 선택, 현재 제외·날짜 기여 제한·부족한 과거 범위, 문맥에 따른 방향 반전, 기간 자동 제안과 필터 변경을 검증한다.
- 기존 애플 요약·취소·보관·복원·근거 복귀·리포트 개인정보 검증을 유지한다.
- 실제 ZIP은 로컬에서만 가져오기·복기·추천·보조 비교를 확인한다. 320px/390px·밝은/어두운 화면에서 가로 넘침과 가독성을 확인한다.
- 단위 테스트·프로덕션 빌드·모바일 Chromium/WebKit 회귀를 통과한다. 자동 브라우저를 실기기 메모리·터치 검증으로 표현하지 않는다.
