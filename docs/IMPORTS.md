# 기록 가져오기와 앱별 내보내기 안내

## 첫 화면

파일을 준비하는 사용자는 **아이폰 / 갤럭시 → 사용하는 앱 → 내보내기 안내** 순서로 진행한다. 휴대폰과 앱은 처음부터 선택하지 않는다. 휴대폰을 바꾸면 하위 앱 목록을 바꾼다.

| 휴대폰 | 안내하는 앱                      |
| ------ | -------------------------------- |
| 아이폰 | 애플 건강, Strava, Nike Run Club |
| 갤럭시 | 삼성헬스, Strava, Nike Run Club  |

휴대폰·앱 선택은 안내를 찾기 위한 용도다. 선택한 앱으로 파일 형식을 강제하지 않으며 실제 내용으로 가져올 수 있는 데이터를 판별한다. 이미 파일을 받은 사용자는 첫 화면의 **러닝 파일 불러오기**로 바로 선택한다. 안내 모달의 **파일 선택하기**도 같은 파일 선택기를 연다. 계정 로그인, 연결 동의, 별도 변환 서비스는 요구하지 않는다.

## 안내 모달

- 앱 이름, 네 단계 내보내기 방법, 선택할 파일, 지원 범위, 공식 안내 링크를 표시한다.
- 네이티브 `dialog.showModal()`로 배경을 비활성화하고 키보드 포커스를 모달 안에 가둔다. 접근 가능한 제목과 파일 설명을 연결한다.
- 닫기 버튼, Escape, 배경 클릭으로 닫는다. 닫힌 뒤 호출한 앱 버튼으로 포커스를 돌려준다.
- 모달이 열려 있는 동안 배경 스크롤을 잠근다. 작은 화면에서는 안내 본문만 스크롤하며 닫기와 파일 선택 버튼은 모달 안에 유지한다.
- 320px 화면, 라이트·다크 테마에서 사용할 수 있어야 한다. 터치 대상은 최소 44px이다.
- 휴대폰 선택, 안내 열기, 공식 링크 방문 여부는 외부로 전송하거나 저장하지 않는다.

## 앱별 파일과 안내

| 앱            | 안내할 내보내기 경로                                                                        | 불러올 파일과 범위                                                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 삼성헬스      | 앱 → 더 보기 → 설정 → 개인 데이터 다운로드 → 다운로드                                       | 삼성헬스 원본 ZIP. 폴더로 내려받은 경우 전체 폴더를 ZIP으로 압축한다. 기존 러닝 요약·상세 분석을 유지한다.                                                       |
| 애플 건강     | 아이폰 건강 → 요약 → 프로필 → 모든 건강 데이터 내보내기 → 파일에 저장                       | ZIP 또는 `export.xml`. 현재 러닝 요약만 시험 지원한다. 시간별 그래프·구간 비교는 지원하지 않으며 실제 기기 내보내기 검증 전이라는 안내를 유지한다.               |
| Strava        | 웹사이트 → Settings → My Account → Download your account → Get Started → Request download   | 이메일로 받은 전체 ZIP 또는 개별 활동의 Export Original 파일. FIT·TCX·GPX와 해당 파일의 gzip 압축을 읽는다. 심박·시간별 데이터 유무에 따라 분석 범위가 달라진다. |
| Nike Run Club | Nike 공식 개인정보 문의 양식 → 계정 정보와 데이터 내보내기 요청 → Nike 회신에 따라 다운로드 | TCX·GPX·FIT, 확인 가능한 활동 metric JSON 또는 해당 ZIP. Nike가 제공하는 파일 종류와 처리 시간을 보장하지 않는다. 임의의 JSON·PDF·HTML은 지원하지 않는다.        |

Strava의 공식 안내는 내보내기를 웹사이트에서 제공한다고 명시한다. 전체 내보내기와 단일 운동 원본 내보내기를 구분하고 원본 파일을 권장한다. Strava 모바일 앱 안에 내보내기 메뉴가 있다고 안내하지 않는다.

Nike 공식 개인정보 양식은 개인 데이터의 내보내기를 요청할 수 있다고 명시하지만 전달 형식·기한을 보장하지 않는다. 앱에 존재한다고 확인되지 않은 즉시 내보내기 버튼이나 특정 ZIP 내부 구조를 약속하지 않는다. TCX·GPX로 제공받을 수 있는지는 Nike에 요청하는 사항으로 설명한다.

## 공식 출처

2026-11-11 기준 공식 도움말을 확인했다. UI의 출처 링크는 아래 문서를 직접 연결한다. 공급자 메뉴는 버전·지역·계정에 따라 바뀔 수 있다.

- [삼성: Download or erase your personal data from Samsung Health](https://www.samsung.com/us/support/answer/ANS10001379/)
- [Apple: Share your data in Health on iPhone](https://support.apple.com/guide/iphone/iph5ede58c3d/ios)
- [Strava: How Do I Export My Strava Data?](https://support.strava.com/en-us/articles/15401919-how-do-i-export-my-strava-data)
- [Nike: Privacy Webform](https://www.nike.com/help/privacy)

안내 데이터는 `src/core/exportGuides.ts`, UI는 `src/components/ExportGuides.tsx`에 둔다. 개인 내보내기 파일, 개인 경로, 실제 건강 수치는 문서·테스트·배포 파일에 포함하지 않는다.

## 파서와 분석 범위

- 파일 확장자나 안내에서 고른 앱에 의존하지 않고 실제 구조로 구분한다. 삼성헬스·Apple 기존 ZIP을 먼저 인식해 부속 경로 파일을 별도 운동으로 중복 가져오지 않는다.
- Strava 전체 ZIP의 `activities.csv`는 `Activity Type`과 `Filename`으로 러닝 파일만 연결한다. 단위가 명확하지 않은 CSV 요약 열은 추정하지 않는다. CSV에만 있고 운동 파일이 없는 수동 기록은 현재 불러오지 않는다.
- GPX는 트랙의 시각과 명시된 심박·속도·거리 확장값을 읽는다. 좌표로 거리나 페이스를 재구성하지 않으므로 일반 GPX에 심박만 있으면 심박 흐름만 보인다. 일시정지 정보가 없으면 운동시간 대신 경과시간임을 표시한다. 트랙 분리 경계를 잇지 않는다.
- TCX의 러닝 활동, 랩 합계·시간별 심박·속도·누적 거리를 읽는다. 명시 속도가 없으면 끊기지 않은 누적 거리·시각 차이로 구한 구간 평균을 구분해 안내한다. 요약만 있는 활동도 열 수 있다.
- FIT는 공식 Garmin JavaScript SDK로 파일·CRC를 검증한 뒤 러닝 세션·기록·타이머 이벤트를 읽는다. 일시정지와 복수 세션을 보존하며 기기 식별자·사용자 정보·위치는 결과에 포함하지 않는다.
- Nike JSON은 단일 활동, 배열 또는 `activities` 배열에서 `type: run/jogging`, 명시 epoch 밀리초, `summaries`·`metrics`의 지원 단위만 읽는다. 요약만 있는 기록과 시간별 기록을 구분한다. Nike는 공식 내보내기 스키마를 공개하지 않으므로 확인한 구조 이외의 JSON과 모든 버전의 호환을 약속하지 않는다.
- 원래 지역 시간대가 없는 UTC 파일은 UTC 날짜로 표시하고 날짜 기반 비교에서 제외한다. FIT의 해당 세션과 일치하는 명시 지역시각, Nike의 유효한 명시 시간대가 있으면 사용한다. 기기 정보가 없으면 같은 기기라고 가정해 자동 유사 기록을 만들지 않는다. 직접 기록 선택은 가능하다.
- 상세 측정 유무로 UI와 보관을 분기한다. 요약 전용 Nike/TCX/FIT도 전체 요약 비교·저장·복원을 지원하며 시간별 값을 생성하지 않는다. 시간대·심박·속도·관측량 요건이 충족될 때만 기존 상세 분석을 제공한다.
- 여러 파일의 시간이 겹치면 중복 가능성을 표시하고 기본 합계에서 제외한다. 사용자가 원본을 확인해 포함할 수 있다.

ZIP은 512 MiB·10만 항목, 개별 표준 파일과 gzip 출력은 128 MiB, Nike JSON은 64 MiB, ZIP에서 읽는 선택 항목 합계는 128 MiB로 제한한다. FIT/TCX/GPX 한 파일은 20만 측정·5천 세션, 전체 가져오기는 5만 러닝으로 제한한다. 파일별 상세는 필요할 때 다시 읽으며 원본 파일·경로는 React 상태·리포트·IndexedDB에 넣지 않는다. 대용량의 실기기 메모리 상한을 보장하지 않는다.

공식 형식 참고: [Garmin FIT JavaScript SDK](https://github.com/garmin/fit-javascript-sdk), [TCX v2](https://www8.garmin.com/xmlschemas/TrainingCenterDatabasev2.xsd), [Activity Extension v2](https://www8.garmin.com/xmlschemas/ActivityExtensionv2.xsd), [GPX 1.1](https://www.topografix.com/GPX/1/1/).

NRC와 Strava를 연결하면 이후 새 활동만 자동 동기화되며 과거 기록을 소급 전송하지 않는다. 계정 연결은 이 앱의 가져오기 전제가 아니며 사용자에게 과거 기록 해결 방법으로 안내하지 않는다. [Strava 공식 Nike 연동 범위](https://support.strava.com/en-us/articles/15401850-nike-and-strava)

검증은 생성한 GPX·TCX·실제 FIT 바이너리·Nike JSON과 ZIP/gzip으로 수행한다. Samsung의 사용자 파일은 로컬에서 회귀 검증하며, 다른 공급자의 실제 개인 내보내기 파일 전체를 검증했다고 표현하지 않는다.

v0.6 검증: 단위 테스트 120개, 모바일 Chromium·WebKit 회귀 30개, 프로덕션 빌드 통과. 별도 Chromium 브라우저에서도 생성한 FIT의 Worker 가져오기·복기·상세 표시와 콘솔 오류 없음을 확인했다. 실제 휴대폰의 메모리·터치 검증을 대신하지 않는다.
